# TOUCHからホームへの映像

バトル画面の既存の16:9の枠内で再生する。ゲームのHP・充電・乱数・敵の動作は進まない。映像中のタップ／クリックはいつでもホームへスキップする。同じタップでSTARTや戦闘開始が発生しない。

## 絵と演出

| 秒 | 内容 |
| --- | --- |
| 最初 | 黒い画面と、STARTと同じ六芒星のTOUCH!。入力前は無音 |
| 0–1.15 | 六芒星に亀裂が走り、黒い画面が割れて白くなる |
| 1.15–2.8 | 白い破片が崩れ、データ化した街へ |
| 2.8–7.2 | 専用の街4コマ、36体のオニヤンマ・ハチ・飛行中の中ボス・蜘蛛・赤ムカデ。ERRORは出さない |
| 7.2–8.4 | 承認済みアカリの顔を参照した、真正面の口元4コマ。ロングソードのボイスは流さない |
| 8.4–10.1 | 黒地に白い専用ドット文字でNo.003!／ロングソード! |
| 10.1–11.35 | 左腕がロングソードのゼロとサモトラケの翼。全体を純黒にした6ポーズと白い横一閃。虫は各スプライトを分解しデータへ。ゼロは翼と一体のまま右へ画面外に抜ける |
| 11.45–13.15 | 街全体が1.7秒かけてゆっくり白くなる |
| 13.15–13.7 | 白い画面を保持する |
| 13.7–15.1 | ホームBGMの開始と同時に、白い画面から既存ホームへ1.4秒かけて移行。完了時も曲を再スタートしない |

地上の虫は足元を204・237・284pxの3段階に分け、高さも17・27・43pxにする。同じ通路の虫は等しい速度で移動・停止するため追い越さず、隣の通路とも重ならない。空中は大きさと速度と濃さを奥行きに合わせて変え、中ボスは既存の開翅フレームを使う。描画は奥から手前の順とし、虫ごとに不規則な高さを与えて積み重なる配置は使わない。

ゼロは既存の `zero-sword-long-v4.png` と `wings-3-v1.png` のNo.003を使用。髪・左右の腕・襟・体型・羽根の輪郭が戦闘素材と矛盾しないよう、6姿勢を一度統合してからCanvasのsource-inで全体を#000にする。白い縁取りや顔の線は付けない。翼の縦横比を保つ。

専用の街とアカリの口元は組み込みの画像生成を使用。原本は `scripts/art-source/prologue-city-v86.png` と `prologue-akari-v88.png`。WebPへの包装は `scripts/package-prologue.py`。ゼロの映像用シートも完全な元画像から再包装し、途中で切れた古いファイルを置き換える。演出用の短いBGMと効果音は `scripts/compose-prologue.py` で別々に生成し、既存の音量設定に従う。

## 生成指示

街：16:9の同じカメラ位置を保った2×2の4コマ。日本の廃都市のビル・高架・店舗がシアンの四角いデータに次第に崩れる。暗い空と小さな橙色の火。精密で大きめのGBA風ドット。文字・HUD・人物・ERRORは描かない。虫は別の既存素材で動かす。

口元：参照は承認済みの `title-akari-v81.png`、編集対象は従来の口元シート。真正面の固定カメラで同じ画角の2×2の4コマ。アカリの鼻先・口・顎・黒髪の一部を大写しにし、決意した技の呼びかけとして口の開き方だけを変える。鼻と口は中央、左右の頬と顎の形は正面の人体として整え、斜め向きにしない。目と頭頂は画角の外。黒い背景とシアンの縁の光。顔の形と肌色とドット品質を参照に合わせ、文字・吹き出し・機器は描かない。

## 最初の戦闘への転送

ホームのSTART後の「エンコードゼロ！」は維持。声の終わりから0.18秒で画面の転送が始まり、0.95秒で戦闘エリアへ。初期パネルの受信リングと四隅が起動し、約2秒かけてデータが集まって足・胴・頭の順で実体化する。色と光が落ち着き、0.55秒後にDEBUG、さらに0.65秒後にTARGETへ。実体化完了時には専用の確認SEを鳴らす。演出中の敵位置・HP・充電は固定し、キャラクターの大きさは変更しない。

## 検証

`tests/dialogue.cjs` はTOUCH前の無音、各シーン、地上の虫の非接触と遠近、飛行中ボス、ロングソード音声の不在、ゼロの全画素の純黒と退場後の翼の不在、白い画面の保持とホームへの連続性、乱数・HP・充電の凍結、各時刻でのスキップ、ホームBGMの即時開始、二重タップ、設定の停止・復帰、音声デコードの初回失敗の再試行を確認する。`ZERO_RENDER_OUT` で実際の描画関数のフレーム一覧を出力する。ブラウザ・iPhone実機での操作確認は別途必要。

TARGETでは画面内を大きなTARGETと敵のNo.だけにする。TARGETは左半分に置き、左上のストックより下、敵の表示より左に収める。敵は暗転後に描き直して識別しやすくし、HPは枠外の標的ボタンにのみ表示。バッテリーの幅は118px、携帯幅では104px以下とし、横に引き延ばさない。
