# TOUCHからホームへの映像

バトル画面の既存の16:9の枠内で再生する。ゲームのHP・充電・乱数・敵の動作は進まない。映像中のタップ／クリックはいつでもホームへスキップする。同じタップでSTARTや戦闘開始が発生しない。

## 絵と演出

| 秒 | 内容 |
| --- | --- |
| 最初 | 黒い画面と、STARTと同じ六芒星のTOUCH!。入力前は無音 |
| 0–1.15 | 六芒星に亀裂が走り、黒い画面が割れて白くなる |
| 1.15–2.8 | 白い破片が崩れ、データ化した街へ |
| 2.8–7.2 | 専用の街4コマ、36体のオニヤンマ・ハチ・蜘蛛・赤ムカデ。ERRORは出さない |
| 7.2–8.4 | 承認済みアカリの顔を参照した口元の4コマ。既存のアカリ音声でロングソードを呼ぶ |
| 8.4–10.1 | 黒地に白い専用ドット文字でNo.003!／ロングソード! |
| 10.1–12 | 左腕がロングソードのゼロとサモトラケの翼。全体を純黒にした6ポーズと白い横一閃。虫は各スプライトを分解しデータへ |
| 12–12.8 | 白い画面から、既存のアカリ主体のホーム画面とホームBGMへ |

ゼロは既存の `zero-sword-long-v4.png` と `wings-3-v1.png` のNo.003を使用。髪・左右の腕・襟・体型・羽根の輪郭が戦闘素材と矛盾しないよう、6姿勢を一度統合してからCanvasのsource-inで全体を#000にする。白い縁取りや顔の線は付けない。翼の縦横比を保つ。

専用の街とアカリの口元は組み込みの画像生成を使用。原本は `scripts/art-source/prologue-city-v86.png` と `prologue-akari-v86.png`。WebPへの包装は `scripts/package-prologue.py`。演出用の短いBGMと効果音は `scripts/compose-prologue.py` で別々に生成し、既存の音量設定に従う。

## 生成指示

街：16:9の同じカメラ位置を保った2×2の4コマ。日本の廃都市のビル・高架・店舗がシアンの四角いデータに次第に崩れる。暗い空と小さな橙色の火。精密で大きめのGBA風ドット。文字・HUD・人物・ERRORは描かない。虫は別の既存素材で動かす。

口元：参照は承認済みの `title-akari-v81.png`。同じ画角の2×2の4コマ。アカリの鼻先・口・顎・黒髪の一部を大写しにし、決意した技の呼びかけとして開き方を変える。目と頭頂は画角の外。黒い背景とシアンの縁の光。顔の形と肌色とドット品質を参照に合わせ、文字・吹き出し・機器は描かない。

## 検証

`tests/dialogue.cjs` はTOUCH前の無音、各シーン、ゼロの全画素の純黒、乱数・HP・充電の凍結、各時刻でのスキップ、ホームBGMの即時開始、二重タップ、設定の停止・復帰、音声デコードの初回失敗の再試行を確認する。`ZERO_RENDER_OUT` で実際の描画関数のフレーム一覧を出力する。ブラウザ・iPhone実機での操作確認は別途必要。

TARGETでは画面内を大きなTARGETと敵のNo.だけにする。敵は暗転後に描き直して識別しやすくし、HPは枠外の標的ボタンにのみ表示。バッテリーの幅は118px、携帯幅では104px以下とし、横に引き延ばさない。
