# アカリの入力欄と端末標準の音声入力（v68）

## 入力

Web Speech APIの音声認識と独自のマイク接続UIを起動経路から撤去した。アカリのinput欄を選び、端末のキーボードにある音声入力ボタンで文字を入れる。マイクの許可・停止・再開は端末の音声入力機能が管理する。ゲームはテキストだけを受け取り、認識モデルや読み辞書を追加取得しない。

画面の確定ボタン・キーボードの決定キーで確定する。入力中の原文は変更せず、指示の解釈だけを既存のlanguage.jsで行う。端末の音声入力から「エンター」「リセット」が文字として届いた場合も処理できる。IME変換中は処理せず、明示されたコントロール文字の更新が450ms落ち着いてから確定する。物理決定は待たずに処理する。普通の語の中に含まれる「エンタープライズ」などは確定語として使わない。入力欄とキーボードの焦点は確定操作で維持する。端末によって音声入力が終了した場合、ゲームが勝手に再開する機能はない。

## 技ストックと標的

文字のある確定は技をストックする。技は登録しただけでは発動しない。空欄で確定すると最初の未確定の技一つを実行可能にする。既に発動中の技がある場合はその終了を待ち、先に登録した順序を守る。後続技は次の空欄での確定を待つ。回数や条件はそれぞれの技に保持する。オートモードは自動で技を選ぶ既存の動作を維持する。

TARGET画面へ入ると待機指示を消去する。すでに発動が始まった技のモーションは終了するまで保つ。一回のTARGETで技を5つまで登録でき、登録した技を発動してもその回の登録数は戻らない。標的確定から10秒間は再選定不可。時間経過による強制再選定は行わず、一時停止中は残り時間を保つ。

左上に技の正方形アイコンを登録順に横並びに描き、先頭の技名・攻撃力・消費率を表示する。従来の技受領枠、画面下のTARGET・状態・装備欄、独自マイク欄は撤去した。ソード名はソード・ワイドソード・ロングソード、ロングソードの範囲は前方2マス。エリア取得にはパケット移動・色の切り替え・パネル浮上のアニメーションを追加した。

## 確認

実行: NODE_PATH=../voice-lab/node_modules node tests/dialogue.cjs

現行の全スクリプトと画像を読み、初回開始、マイク接続をしないこと、入力と決定、IME途中、音声入力から届く文字、五つ制限、標的の変更制限、順序、手動の一技発動、回数指定、不発指示の消去、ロングソードの2マス判定、攻撃モーション保持、オートモードを検証する。ゲーム内のアイコンとエリア演出もcanvasで描画して確認する。

これらは入力イベントを模擬したテスト。iPhone実機のキーボード・音声認識精度・キーボード表示中のレイアウトはこの環境では未検証。以前のtests/battle.cjsとtests/voice-continuous.cjsはv67までのブラウザ音声入力の検証記録で、現在の入力方式向けの実行テストはtests/dialogue.cjsである。
