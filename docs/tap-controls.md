# タップ指揮（v73）

音声入力と文字入力は廃止。戦闘画面の直下に全19技を常設する。画面サイズに関係なく5行4列に固定。1〜5行目はソード・ガンズ・シールド・ウィング・グラビティ。各行の左3列にNo.001〜003を並べ、右端列の上4段にエリアNo.001〜004を置く。右下はCancel。DOMのフォーカス順も行ごとに一致させる。タブや技選択用の開閉操作はなく、技名・威力または補助効果・消費量を各ボタンに表示する。長い名前は2行に折り返す。

TARGET中に5つまで技を蓄積できる。登録は既存のsubmitOrderの手動指示として扱い、1度のTARGETサイクルで最大5件、消費済みの登録回数は補充しない。TARGETを新しく開くと未使用ストックと登録回数をリセットする。攻撃がすでに始まっている場合のモーションは維持し、その攻撃を新しい5枠には含めない。蓄積した技は標的決定だけでは発動せず、「技を使う」で先頭から1件ずつ確認してFIFO実行する。待機ストックがない戦闘中のタップは登録と使用をまとめて行う。登録の5回制限はその操作にも適用する。

TARGETは敵または番号ボタンをタップして決定。番号ボタンは盤面を覆わない固定の操作列に表示する。標的変更の10秒制限と既存の攻撃モーション固定は維持。TARGET中は5つのストック枠を空欄も含めて表示する。

アカリのボイスは廃止。技の登録と実行には、ファイルの種類ごとに異なる短い電子音のSEを即時に鳴らす。開始時も転送用の電子音を鳴らす。音声ファイルのダウンロード・デコード・発声待ちは発生しない。新しい操作音が来たら前の操作音を止める。BGMのソース・再生位置・ゲインは変えない。SEの音量とミュートはメニューのSEスライダーに従う。アカリのセリフと正式な技名の文字表示は維持する。

検証：tests/dialogue.cjsで19技すべての実行、単発使用、連続タップFIFO、モーション保持、翼と盾、着地、標的選択、充電不足、オート終了を確認。tests/audio.cjsで19種類の操作音・開始SEの即時実行、前のSEの停止、BGM共存、音量、ミュート、中断復帰、音声ファイルの取得がないことを確認。iPhone実機とブラウザーでの音出し確認は未実施。
