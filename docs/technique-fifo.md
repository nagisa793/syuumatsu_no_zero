# 技の蓄積と順番の実行（v63）

発声した「エンター」で確定した技を、一つずつ独立した指示として蓄積する。別の発声で追加された技も末尾に並べる。実行中の技・回数指定・撃破までの繰り返しを、新しい技で置き換えない。

同じ入力内のファイル名、番号、技名、接続語を順に解釈する。番号だけが続く場合はその入力内の直前のファイル名を引き継ぐ。回数や撃破までの条件だけが後続する場合は直前の技へ適用し、別の技を勝手に作らない。別の入力で条件だけ追加した場合も、最後に受け付けた実行待ちの技へ適用する。

TARGET中も蓄積できる。標的選択を技の後ろへ並べると戦闘開始できなくなるため、TARGET中の標的選択は直接通す。その時、標的を明示していない待機指示と撃破条件に選ばれた番号を適用する。標的が明示された技は指定を保持する。

先頭の技が完了するか不発になったら次の技へ進む。不発によって後続の指示を消さない。戦闘が終了した場合は従来どおりその戦闘の待機指示を終了する。キャンセルは明示した場合に処理する。音声の生の文字列を保持し、補正を確定後に行う仕組みは維持する。

## 検証

`node tests/battle.cjs` の既存テストと追加テストを実行した。

- 独立した複数の入力による追加と、技の発動中の追加。
- TARGET中の蓄積、標的選択、条件の標的更新、戦闘への移行。
- ファイル混在、省略した番号、接続語や区切り方の異なる入力。
- 回数だけの追加と、撃破まで繰り返す技の後ろへの追加。
- 先頭の条件終了後の継続、不発が混ざった場合の継続。
- 8回の入力で24個の技を蓄積し、全24個が入力順に実行されること。
- 音声認識イベントで別々に確定した技が同じ待機列へ並ぶこと。

実際のゲームコードを使うシミュレーションで確認した。物理マイクでの認識精度はこのテストの対象ではない。
